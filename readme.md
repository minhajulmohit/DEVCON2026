# 🚀 DevCon2026

DevCon2026 is a modern developer conference landing page built with HTML and CSS. The website provides information about conference speakers, ticket pricing, event schedules, and networking opportunities through a clean and responsive user interface.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome

---

## ✨ Main Features

* 🎤 Conference speakers section
* 💳 Multiple ticket pricing plans
* 📅 Three-day conference schedule
* 🧑‍💻 Modern developer conference design
* 📱 Responsive layout
* 🔗 Social media links
* 📝 Conference registration buttons
* 🎨 Clean and professional user interface

## 💻 Run the Project Locally

Follow these steps to run the project on your local machine.

### 1. Clone the repository

```bash
git clone https://github.com/minhajulmohit/DEVCON2026.git
```

### 2. Go to the project folder

```bash
cd DEVCON2026
```

### 3. Open the project

You can simply open `index.html` in your browser.

Or, if you are using VS Code, install the **Live Server** extension and click:

**Right Click → Open with Live Server**
